:Vim C Cheatsheet

coc.nvim · clangd 22 · gruvbox

leader = \

Workflow

  1. cd into projectproject root with sources
  2. bear -- makeonce, or when flags change
  3. vim main.cclangd picks it up
  4. write codecompletion & errors live

Code navigation

gdgo to definition
grall references
gygo to type
gigo to implementation
Kdocumentation under cursor
]g / [gnext / previous diagnostic
Ctrl+o / Ctrl+ijump back / forward

Completion

Tabnext item in the list
Shift+Tabprevious item
Enterconfirm the selection
Ctrl+Spacetrigger manually

Refactor & format

\rnrename symbol everywhere
\cacode action (quick-fix)
\hswitch .c ↔ .h
\fformat (clang-format)
:FormatOnSaveToggleformat on every :w

Build & quickfix

\mrun :make, errors to quickfix
]q / [qnext / previous error
Enterin quickfix: jump to the error
:ccloseclose the quickfix list

Debugging (gdb)

\ddstart: :Termdebug ./prog
\db / F9breakpoint on this line
\dxclear breakpoint
\drrun
\dc / F5continue
\dn / F10step over
\ds / F11step into
\dffinish function
\de / Kevaluate under cursor

Git

\ggstatus (fugitive)
\gbblame
\gddiff against index
]c / [cnext / previous hunk
\gppreview hunk
\gs / \gustage / undo hunk

Snippets

main for iftype, pick from menu, Enter
Ctrl+j / Ctrl+knext / previous placeholder
guard st swinclude guard, struct, switch
pr mal incprintf, checked malloc, #include

Files, search, edit

Ctrl+nfile tree (NERDTree)
:Filesfuzzy-find files
:Rg textsearch by content (ripgrep)
\cSpacetoggle comment
ysiw"wrap word in quotes
cs"' / ds"change / delete surround

coc / clangd commands

:CocInfococ diagnostics (is clangd alive)
:CocList diagnosticsall project errors
:CocList extensionsinstalled extensions
:CocCommand clangd.switchSourceHeaderjump .c ↔ .h
:CocCommand clangd.symbolInfosymbol info under cursor

Plugins & upkeep

:PlugUpdateupdate plugins
:CocUpdateupdate coc extensions
compile_flags.txtone file instead of bear: one flag per line
